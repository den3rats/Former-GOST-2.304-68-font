# Former-GOST-2.304-68-font
Historical font according to former GOST 2.304-68. 
Just for reconstruction purpose.
Developed and generated in FontForge v.20251009

GOST 2.304-68 is a withdrawn USSR standard for the lettering used in engineering documentation (paper drawings, associated specifications, etc.). 
In the subsequent GOST 2.304-81  (from 1981), the characters were slightly adapted for computer technologies.
At the same time, they became thinner, simpler, and more angular.
In contrast, the 1968 typeface inherits the letterforms of hand-lettering—features largely derived from the even older GOST 3454-59 standard (from 1959).

Differences from the original GOST and known issues:
 - Kerning is based on visual harmony rather than GOST standards. And it isn't perfect everywhere;
 - Character shapes were created entirely from scratch, though the source material wasn't always legible;
 - I realized too late that I should have converted the "Regular" style to "Italic" before applying stroke weight. But it was already too late, so I finished the work as is.
